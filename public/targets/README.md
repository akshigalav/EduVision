# EduVision AR - Predefined Image Targets (Phase 3)

This folder contains image targets for Web-based Augmented Reality using MindAR.

### Files:
1. `heart-target.png`: The visual image card that the student points their camera at.
2. `heart-target.mind`: The compiled binary feature map loaded by MindAR to track the target in real time.

### How to Compile or Change Image Targets:
1. Visit the free MindAR Web Compiler:
   https://hiukim.github.io/mind-ar-js-doc/tools/compile
2. Upload your high-contrast card image (`.png` or `.jpg`).
3. Click "Compile" and download the generated `.mind` file.
4. Rename it to `heart-target.mind` and place it in this folder.
