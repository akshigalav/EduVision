# 3D Model Directory: Human Heart (Phase 2)

Place your 3D model file in this folder with the filename:
`heart.glb` (or `heart.gltf`)

### Full File Path:
```
eduvision-ar/public/models/heart.glb
```

### How the Model Loader Works:
1. The Three.js viewer automatically looks for `/models/heart.glb` when the Human Heart topic is loaded.
2. If `heart.glb` is present, it will load and display your realistic 3D heart model with 360° rotation and zoom.
3. If no file is placed here, the application automatically displays the built-in procedural 4-chambered heart placeholder model, ensuring all interactive controls, chamber labels, and camera resets continue to work.

### Recommended Free 3D Heart Models:
- **Sketchfab**: Search for "Human Heart GLB" (filter by "Downloadable" and CC Attribution)
- **Poly Pizza**: https://poly.pizza (low-poly web-friendly models)
- **NIH 3D**: https://3d.nih.gov
